Gradient Dracula · 词内逐字母渐变

复刻 VSCode gradient-theme 的核心：每个彩色单词内部，从第一个字母的深色端，逐字母过渡到最后一个字母的浅色端（终端用 extmark 逐字符上色实现）。下面每个字母的颜色都由主题 Lua 引擎实际计算。

Neovim 实际渲染（Dracula 底色 #282A36）
keyword 关键字 深粉→亮粉 function 函数 深绿→亮绿 parameter 参数 深橙→亮橙 number 数字 深紫→亮紫 string 字符串 保持原样（不渐变）
放大看单个词：首字母深 → 尾字母浅
实现要点
VSCode 做法background-clip:text + linear-gradient 在一个词内连续渐变
Neovim 做法treesitter 定位每个彩色词的边界，按字母在词内位置 t=i/(n-1) 用 mix(deep, bright, t) 插值，逐字母 extmark 上色（priority 高于语法高亮）
普通变量 / 标点保持前景色不渐变，只有彩色词流动，避免整屏花掉
开关:NvimpireGradientFlow on|off，或 flow = { enabled = true }
